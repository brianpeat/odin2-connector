# Odin 2 + Preset Connector (test fork)

This fork adds a Preset Connector handler to Odin 2 (https://github.com/brianpeat/PresetConnector).
Odin 2's 260 factory presets are baked into the plugin binary; the connector exposes them (list/get/load/exportState/current)
over the AU property doorway.

Changes: `Source/PresetConnectorOdin.cpp`, `Source/PresetConnectorCatalog.h` (generated by `scripts/generate_connector_catalog.py`),
`connector/` (reference headers), plus two patches to the bundled JUCE 6.1.6 in `patches/`:
- `juce-au-preset-connector-hook.patch`: lets a plugin that implements `presetconnector::Handler` answer the AU property.
- `juce-macos15-sdk.patch`: build fix for current macOS SDKs (not part of the connector).

Build (macOS, arm64):
```
git submodule update --init --depth 1 libs/JUCE libs/json libs/tuning-library
git submodule update --init --depth 1 --recursive libs/clap-juce-extensions
git -C libs/JUCE apply ../../patches/juce-macos15-sdk.patch ../../patches/juce-au-preset-connector-hook.patch
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_OSX_ARCHITECTURES=arm64 \
  -DCMAKE_OSX_SYSROOT=$(xcrun --show-sdk-path) -DODIN2_COPY_PLUGIN_AFTER_BUILD=OFF
cmake --build build --target Odin2_AU
```
